- 飞书要求 callback 响应 3 秒内返,我们的 approve 链写 DB + 审计 + Redis stream 可能超时
- **稳的方案**:callback 响应**只返 toast**(快),后台 task 调飞书 **PATCH /im/v1/messages/{message_id}** 主动更新卡片
- **需要做的改动**:
  1. `sre_action_plans` 加 `message_id VARCHAR(64)` 列(`sql/migrate_add_message_id.sql`)
  2. `feishu.send_approval_card()` 发送成功后 UPDATE plan 的 `message_id`
  3. `api/app.py` callback 处理完 approve 后,启动 background task 调 PATCH
  4. 加 `CorpAI/platform/sre/card_patcher.py` — PATCH 逻辑(读 plan.message_id + 组装新卡片 + POST 到 `https://open.feishu.cn/open-apis/im/v1/messages/{message_id}`)
